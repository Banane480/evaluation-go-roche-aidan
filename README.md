# Évaluation Go

Nom : Roche

Prénom : Aidan

## Exercices

### Exercice 1
Programme qui simule un distributeur de boissons. L'utilisateur choisit une boisson dans le menu, entre son argent, et le programme calcule la monnaie ou redemande s'il manque des sous. La boucle permet de recommencer jusqu'à taper 0 pour quitter.

### Exercice 2
Programme qui demande un nombre de notes, vérifie qu'elles sont bien entre 0 et 20, puis calcule la moyenne, la note max et la note min. Il affiche si l'élève est admis et inclut le bonus avec les appréciations et le nombre de notes au-dessus de la moyenne.
